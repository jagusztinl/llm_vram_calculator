    Formulas and assumptions

    Model weights

    parameters × bits/weight ÷ 8

    Bits per weight include GGUF/MXFP4 scale and block overhead (Q4_K_M ≈ 4.85). The Native option uses the effective bits per weight inferred from the distributed checkpoint size.

    KV cache

    Σ 2 × KV heads × head_dim × tokens × bytes

    Full attention uses the complete context; SWA uses min(context, window). MLA uses latent dimension × context (without ×2). Linear-attention layers contribute fixed state. Multiply by the number of concurrent requests.

    Runtime

    per-GPU reserve + 512 × vocab × 4 bytes + 0.25 GiB

    CUDA/Metal context, logits buffer and activations. Reserve at least 0.5 GiB per discrete GPU. Runtime overhead is heuristic; actual allocations depend on the backend and configuration. The safety margin is applied to this overhead as well.

    Decode throughput

    1 ÷ (active weights ÷ (BW × η) + KV bytes read ÷ (BW × η) + layers × 15 µs)

    Efficiency factor η: GPU 0.75, Apple/unified 0.7, CPU 0.6. For MoE, multiply the weight-read efficiency by 0.65. Offloaded weights use system RAM bandwidth with a 0.6 factor. Tensor parallelism assumes ≈ N × 0.85 effective bandwidth; layer-wise splitting does not increase bandwidth.

    Speculative decoding

    speedup = accepted tokens/step ÷ (1 + draft overhead)

    An integrated MTP head is modeled with ~1.8–2 accepted tokens per step and ~10% overhead (≈1.7× speedup). A separate draft model may increase accepted tokens but incurs higher overhead. The model reduces the speedup as concurrent requests increase.

    Calibration

    multiplier = measured ÷ estimated (pp512, tg128)

    The tg128 calibration reference uses a short context with speculative decoding disabled. Calibration multipliers are scoped to the hardware, model, quantization and KV-cache settings.

    Prefill / TTFT

    prefill = 2 × active parameters × prompt ÷ (TFLOPS × 0.35); TTFT ≈ prefill + first decode

    Compute-limited heuristic. Offloading adds estimated PCIe transfer overhead. TTFT does not include network latency, queueing or runtime initialization; it is not a service-level guarantee.

    Concurrent requests

    step = max(weight reads + N × KV reads, N × 2 × active ÷ TFLOPS)

    Dense models share the weight-read cost across batched requests. For MoE, different requests activate more experts; this is approximated using N^0.6.

    Payback

    full-system CAPEX ÷ (cloud cost − electricity − operations)

    Machine time = output tokens ÷ aggregate tokens/s + uncached input tokens ÷ prefill throughput. Additional machines are needed when daily processing exceeds available capacity. TCO = (full system price × (1 − residual fraction) ÷ depreciation months) + electricity + operations. A discrete GPU requires separate host inputs.

    Quality

    Artificial Analysis Intelligence Index

    Artificial Analysis Intelligence Index v4.3.2 scores where available. An asterisk indicates an older index version that may not be directly comparable. The comparable-quality button selects the cheapest cloud API with a score no more than 2 points below the local model.

    Loading config.json

    layer_types · full_attention_interval · hybrid_override_pattern · kv_lora_rank

    Layer types and KV geometry are read from config.json. Total parameter count is obtained from Hugging Face safetensors metadata when available, otherwise estimated from architecture. Active parameters are estimated from expert counts.

    Not modeled

    The implementation details of FlashAttention and quantized kernels, exact KV dequantization cost, thermal throttling, inter-GPU communication, queueing and some linear-state allocations. The tokens/s error is not validated to ±20%; verify against your own measurements.
